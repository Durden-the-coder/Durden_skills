# Scientific Critical Thinking

A companion skill for evaluating scientific reasoning and evidence. It covers experimental design, controls, confounding, bias, statistical interpretation, evidence grading, logical fallacies, and the fit between a claim and the study that supports it.

## Files

- `SKILL.md`: entry point and usage guidance
- `references/`: detailed guidance on methods, bias, statistics, evidence hierarchies, fallacies, and experimental design
- `LICENSE`: MIT license, as declared in the source skill metadata

## Install and use

Copy this directory to `~/.codex/skills/scientific-critical-thinking`. Invoke `$scientific-critical-thinking` for a focused evaluation of a study, experimental design, or manuscript claim.

## Provenance
