# Academic Humanizer

A companion skill for editing academic papers and funding proposals. It audits before rewriting, removes generic or inflated phrasing, matches the author's scholarly voice, and keeps claims, numbers, results, and citations intact. It also reminds users to follow the venue's AI-use disclosure policy.

## Files

- `SKILL.md`: complete workflow and writing guidance
- `LICENSE`: MIT license and upstream attribution

## Install and use

Copy this directory to `~/.codex/skills/academic-humanizer`. Invoke `$academic-humanizer` when polishing a manuscript, abstract, rebuttal, or proposal.
