# Changelog

## v0.2.1 — 2026-07-30

- Added flexible 72-hour, 96-hour, 7-day, 30-day, and custom time windows.
- Expanded the default detailed output to 20 research items.
- Added journal-prestige ranking with Nature, Science, and Cell prioritized.
- Restricted clinical-journal monitoring to NEJM and The Lancet.
- Added publication dates to displayed records.
- Added a bounded trend/commentary section for AI-relevant non-primary content.
- Added mandatory JSONL auditing before final report rendering.
- Added safeguards for Review/Perspective routing, unsupported Letters, and AI terminology collisions.
- Added dedicated regression coverage for Nature Methods and Cell Metabolism.
- Added window-aware index limits and UTF-8 BOM Markdown output.

This public version corresponds to the internally tested V3.2.1 line.
